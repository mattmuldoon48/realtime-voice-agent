↳ BACKED BY DynamoDB + CloudWatchExplore the architecture ↗

Handling interruptions

Audio flows in both directions, and the runtime clears queued playback when you interrupt the agent.

Per-call isolation

Each call owns its session, bounded queues, and cleanup so one conversation doesn’t block another.

Safeguards for a public demo

Requests are authenticated before admission checks apply caller and capacity limits, with calls capped at five minutes.
