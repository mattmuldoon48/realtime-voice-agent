WELCOME / PROJECT ABSTRACT

Welcome to the live voice lab.

This project is a working real-time voice system, not a recorded product tour. Call the public number, select a configured agent, and speak naturally. The phone audio is authenticated, converted, streamed to Nova, and returned to the caller in real time.

One isolated session owns the resamplers, bounded queues, model stream, lifecycle, persistence, and telemetry for each call. Personas are versioned configuration rather than separate applications.

OPERATOR'S NOTE

Portfolio demonstration only. Do not provide real medical, financial, authentication, account, or other sensitive personal information.

FIELD NOTES / ENGINEERING INDEX

What the demo is proving.

Inspect the source ↗
A.01

Full-duplex audio

Stateful μ-law/PCM conversion and bidirectional streaming without file containers.

A.02

Authenticated ingress

Exact-URL signature checks at Twilio webhook and WebSocket boundaries.

A.03

Versioned personas

Prompts and voices are configured in DynamoDB and snapshotted per call.

A.04

Bounded pipelines

Backpressure, queue limits, retries, and idempotent terminal cleanup.

A.05

Privacy-aware signals

Logs omit phone numbers, raw audio, prompts, and transcript text.

A.06

Public-demo controls

Caller rate, global concurrency, duration, and rolling budget limits.

A.07

Durable lifecycle

On-demand persistence with deterministic outcomes and retention controls.

A.08

Automated confidence

192 tests cover protocol drift, audio, failure paths, and infrastructure contracts.
